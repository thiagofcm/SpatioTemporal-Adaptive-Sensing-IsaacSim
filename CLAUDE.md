# Project instructions

## Git

The user manages all Git operations.

- Do not create Git commits, even after an implementation is complete and validated.
- Do not stage files, push, merge branches, or create branches or tags without the user's explicit authorization.
- Do not modify the existing Git history.
- At the end of each implementation, give a summary of the changes and a suggested commit message.
- Suggested commit messages must not contain AI co-authorship or attribution trailers (no `Co-Authored-By`, no
  "Generated with" lines).
