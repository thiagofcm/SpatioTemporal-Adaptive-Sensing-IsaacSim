# Visual comparison: between-deck mounts with a narrower vertical FoV

Five mounts on the same recorded frame:

| Mount | Position, pitch, vertical FoV | Colour |
|---|---|---|
| Original M7 mount | (0, 0.40), 5°, 14° | grey |
| R4 | (0, 0.40), 6.75°, 14° | magenta |
| R1 | (0, 0.50), 7.5°, 14° | green |
| B10 | (0.086, 0.298), 4°, 10° | orange |
| B8 | (0.086, 0.298), 3.25°, 8° | blue |

Frame: NAV03 episode 56, step 15, with both moving obstacles in view. Generated by
`../../scripts/visual_comparison_xzfov.py`.

The rendering is offline, as for `../visual_comparison/`. The Mirrorcle enclosure (85 × 84 × 73 mm) is drawn to scale
and centred on the optical centre (assumed).

| File | Content |
|---|---|
| `1_mounting.png` | Side, front, top and isometric views. Marks the top platform, the plate underside and the original 2D LiDAR height (red ×). |
| `2_scene.png` | 3D scene with point cloud and FoV frustum, top-down view, and side view (distance from the robot centre). |
| `3_pov.png` | First-person view, range image and ray-class image, on a common ±7° elevation axis. Outside a narrower FoV the axis is greyed out. |
| `4_animation.mp4` | The whole of episode 56 (163 steps, 2× real time), all five mounts side by side. Top: LiDAR point of view. Bottom: top-down view with the obstacle-ray count, floor % and escaping %. Scans are acquired at 4 Hz and held between acquisitions, as in the environment. `4_animation_frame_selected.png` is the frame at step 15. |
| `selection.json` | Per-mount frame and episode statistics. |
